# Cabinet Grotesk

Body face for the site. Indian Type Foundry, Fontshare.

License: ITF Free Font License 2.0 (17 Aug 2026).
https://www.fontshare.com/licenses/itf-ffl

Self-hosting on this site is allowed. Redistributing the font files from a
public repository is not, and subsetting is not. `scripts/fetch-fontshare.mjs`
downloads the official woff2 files at build time. Those files are gitignored.

`font-display: swap` is set in the generated `faces.css`.
