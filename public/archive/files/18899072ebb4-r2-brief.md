# Artometrics R2 upgrade brief (house standard, from the Anime R2)

Audience: industry CEOs and elite professionals. Framing: consultant/researcher pitch — one clear unfolding story. Every pattern states (1) what it means, (2) how we know it (data source + method), (3) what explains it (economic shifts, technology, who could buy, affordability of distribution, market/biographical/cultural history), with cross-market comparisons and counterexamples. Metric-heavy, direct, witty, verified-only. Never fabricate numbers, quotes, or sources; unverifiable claims get softened/removed or an HTML TODO comment (stripped from the rendered page).

Deliverables in the article's folder (articles/<slug>/):
- Executive summary up top, method/data box, decision tools for executives, named examples (titles, companies, people) with context, profiles, counterexamples, deeper sections.
- 5-8 charts built from data files committed under data/ (with source + licence notes), house style: red/blue anaglyph palette ("3D glasses") with black/white support; DM Sans text, DM Mono numbers; Chomsky only for the Artometrics wordmark.
- references.bib with verified academic + industry sources (DOIs/URLs checked; use OpenAlex/Crossref/Semantic Scholar/Unpaywall APIs).
- Many more visuals: official stills/logos where licensed, Wikimedia Commons, Pixabay; credit every image in a CREDITS file. No generated real people, no copyrighted characters.
- Keep the live page (src/content/blog/<slug>.md or however this repo publishes) in sync with the .qmd source; npm run build must pass.
- VIDEO PACKAGE in articles/<slug>/video/:
  - script-short.md: ~3 min explainer narration in the style of the Anime explainer (punchy, consultant voice, numbers spoken with pauses, ~420-480 words).
  - script-deepdive.md: 10-15 min full deep dive (~1500-2200 words) covering the whole story, all charts, profiles, counterexamples.
  - script-vertical.md: standalone 60 s 9:16 story (~140-160 words) with its own hook, 2-3 key numbers, and a payoff ending. NOT a trim of the long one.
  - storyboard.json for each script: ordered scenes, each {id, narration_text (exact substring of script), type: big_number|chart_beat|official_still|logo|ai_illustration|quote|title_card, on_screen_text (minimal), number_to_count_up, red_box_target, chart_id, image_source (path/URL + credit) or ai_prompt (style: anime-style or stick-figure or realistic, no real people/copyrighted characters)}. Aim for a new scene every 3-5 s (short), 4-7 s (deep dive), 2-3 s (vertical).
Open a PR (ready for review, not draft) with screenshots of the top of the page and every chart. Report PR link, chart list, sources added, and anything needing Kyle.
