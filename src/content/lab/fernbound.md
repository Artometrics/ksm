Fernbound was a canvas game. The Drive README says it is to be merged into Dawn as a Pokémon-style feature: hunt real monsters and spirits from history near you. The host was [fernbound-510519.web.app](https://fernbound-510519.web.app). There is no GitHub repo. The source named in the README is `/workspace/fernbound-deploy`.

## What it was

A small static web game, 11 files in the working-tree zip, and a much larger byte count (11,981,445) than the file count suggests. The KSM inventory, from before this archive, could only verify the page title. The 13 Nov README is the description I am using.

## Why it was built

The README states the Dawn feature, not a studio backstory. Walk near where you are, and meet a spirit that belongs to that place. The index says that decision was already made, and that the box copy should not be deleted until the Dawn merge exists.

## How it worked

Canvas, static web, Firebase Hosting. Offline, serve `public/` with `python3 -m http.server`. No git history was available. The package is the working-tree zip and a live mirror (95,381 bytes).

## What I learned

Eleven files can still be a game if the art is most of the zip. The merge instruction is the part worth keeping: do not throw out the only copy before Dawn has the hunt. On 13 Nov the inventory says Dawn was not changed.

## Where it went

Dawn, as a planned fold. On 14 Nov 2026 a code search of `Artometrics/dawn` for fernbound returned no matches. GitHub marked that search incomplete, so the miss is not proof the name is absent. The standalone source is still the Drive zip. The index does not record a repo delete, because there was no repo.
