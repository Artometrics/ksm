Skins was a board of magazine skins: style directions, open skins, and sample issues. The Drive README quotes the live title as "Artometrics, magazine skins & style board." The host was [artometrics-skins-510519.web.app](https://artometrics-skins-510519.web.app). No dedicated GitHub repo was found.

## What it was

A static style board. The likely source in the README is `/workspace/artomag/styles-board`. The box folder `/workspace/skins` only had `spec.md`. Four mobile-mockup PNGs were copied from `/workspace/mobile-mockups/skins`. The decision to archive and retire it was recorded at 6:25 PM PT on 13 Nov 2026, the same minute as the magazine mockup.

## Why it was built

The README describes the board as the place where skin directions and sample issues could be opened together. It sat next to the magazine mock, in the same `artomag` tree.

## How it worked

Static files. Offline, serve `styles-board` or the live mirror with `python3 -m http.server`. The working-tree zip is 24 files and 8,370,260 bytes. The live mirror is 1,411,687 bytes. The README says the live wget mirror is the most complete capture of what was hosted.

## What I learned

The spec folder and the hosted board were not the same size. `/workspace/skins` was a `spec.md`. The hosted page lived in `styles-board`. Archiving only the spec would have kept the note and lost the board. The mirror was the check.

## Where it went

Retired. The index says the host was deleted at 6:38 PM PT. The fold column on that row is blank. Nothing is recorded as moving into Dawn, Bagel, or Pantheon.
