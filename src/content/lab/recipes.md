Recipes, on the host [recipes-510519.web.app](https://recipes-510519.web.app), was Style Recipes. The Drive README is blunt about the name: a style board, not food. No GitHub repo. The box path was `/workspace/recipes`.

## What it was

A static Firebase Hosting site for looking at styles. The working-tree zip is 12 files. The KSM inventory, written earlier, could only verify the page title. The 13 Nov archive README is the fuller description, and it stays at "style board."

## Why it was built

Styles needed a board that was lighter than Style Lab. The decision line says this one was already inside Dawn, which is the reason the standalone host could go.

## How it worked

Static hosting. Offline, serve `public/` with `python3 -m http.server`. There is no git history in the package. The working-tree zip is 1,998,137 bytes. The live mirror is 13,336 bytes.

## What I learned

The name lied a little, and the README corrects it. Treating it as a cookbook would have archived the wrong thing. The recorded confirmation is that the board already lived in Dawn, so the host was duplicate surface.

## Where it went
