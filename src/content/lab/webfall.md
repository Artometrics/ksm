Webfall was a Rainfall Health URL, [webfall.web.app](https://webfall.web.app). When it was archived, the live page was Firebase's Site Not Found. No source tree was on the box. No repo was found under Artometrics or kylesmcauliffe.

## What it was

A host name with a 404. The Drive README says the stack is unknown, because the only artifact was the Hosting URL. The live mirror zip is 15,647 bytes. That is the saved 404, not an app.

## Why it was built

The README calls it Rainfall Health work and says I later approved archiving a copy and then retiring it. It also says this was the one Rainfall exception. Stratus, Stratus AO, and sandbox were to stay untouched. The README does not describe a feature list, because there was nothing deployed to read.

## How it worked

Unknown. Offline, serve the mirrored 404 HTML if a page is needed. There is nothing to rebuild.

## What I learned

A dead Firebase host still needs a row, or it keeps looking like a missing app. The page that came back was Site Not Found. Saving that page closed the question. A later index row says Webfall was already gone, that it was not among the 27 Firebase projects on team@artometrics.com, and that any repo would live in a different Rainfall org, which was not touched.

## Where it went

Retired, in the sense that nothing was left to delete on the Artometrics side. It did not move into Dawn, Bagel, or Pantheon.
