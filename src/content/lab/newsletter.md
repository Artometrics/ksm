Newsletter was the Artometrics letter. Public signup, confirmation, compose, send, and an archive of sent issues. No GitHub repo. The box path was `/workspace/newsletter-dep`. The host was [newsletter-510519.web.app](https://newsletter-510519.web.app).

## What it was

A studio letter, and the inventory's first recommendation for a Dawn merge. The desk is Vite, React, and TypeScript, with Cloud Functions and rules tests. Hosting reads `/__/firebase/init.json`, which the note calls Spark-friendly. The desk is allowlisted. Until functions are deployed, the live desk says the back end is not enabled.

## Why it was built

The magazine needed a letter that could take a signup with consent, send, and then show the issue in public. That is the feature list the inventory records, and the reason it ranks first.

## How it worked

Stored consent, double opt-in, a markdown composer, a Gemini draft from notes or a URL, send in batches of 50, `List-Unsubscribe`, an open pixel, rewritten clicks, unique and total counts, and MCP tools for count, draft, schedule, send, and stats. Firestore (default) existed and was described as the likely home of subscribers.

Offline: `npm install` and `npm run dev`. Sending mail needs functions and is a dry run in the emulator.

The delete row on 13 Nov 2026 says Firestore was empty (no subscribers), the project delete was requested at 8:22 PM PT, the host was 404, and the source was kept on the box at `/workspace/newsletter-dep` for Dawn. A document export was not run.

## What I learned

The letter was finished as a desk and empty as a list. No subscribers were in Firestore when it was deleted. The machinery (consent, double opt-in, batch send, unsubscribe) is what the inventory says to keep. The audience was not in the database.

## Where it went

The recorded destination is Dawn, as Newsletter. The 13 Nov inventory says Dawn was not changed that night. On 14 Nov 2026 a code search of `Artometrics/dawn` for the word newsletter returned no matches. GitHub marked that search incomplete, so this is not proof the word is absent. I still cannot point at a Dawn file from that search. The zip, and the box path named in the delete row, are the source for that merge.
