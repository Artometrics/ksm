## What it was

The project README says "Cardinal Quest — Stanford map game." Allow location and walk to the campus landmarks to unlock history cards and XP. There is a daily three-landmark hunt. The README also says "The One Piece of Land walk has spoken bridge lines built only from the cited facts in the land thread."

The archive README says this is not the Cardinal site at stanford.phd. Live URL: https://cardinal-quest-510519.web.app. Repo: https://github.com/Artometrics/cardinal-quest. A box copy was noted at `/workspace/games/stanford` for the same Firebase site.

## Why it was built

The README is the play description. The archive index says retire the standalone site, and either fold it into Dawn as a location hunt or reuse it in the Cardinal rebuild. That is an index note, not a completed merge.

## How it worked

`public/index.html` loads MapLibre GL 4.7.1 from unpkg, plus `data.js` and `threads.js`. Title "Cardinal Quest," `noindex,nofollow`, theme color `#8c1515`. The page registers `sw.js` on https or localhost. `firebase.json` hosts site `cardinal-quest-510519` from `public/`. There is no `package.json` and no `project.godot`.

`public/data.js` starts "Generated by tools/build.py from tools/landmarks.py." It contains 27 `"lat"` fields. The project README still says 14 campus landmarks. Both numbers are in the tree. The v0.3 commit subject says "6 new sourced landmarks (27)." `const SPOTS`, `const ROUTES`, and `const EVENTS` follow. EVENTS includes years from 1876.

`public/sw.js` first line is "Cardinal Quest v0.4 offline cache." It precaches `./`, `index.html`, `data.js`, `threads.js`, and the MapLibre URLs. `public/threads.js` is generated by `tools/threads.py`. It includes a thread id `rail` titled "The Railroad Fortune" and the One Piece of Land material. `data/locations.json` is titled "Cardinal Quest campus location catalog" and has 24 entries. `tools/test_locations.py` is in the tree.

Ten commits, HEAD `ff16ac46624e`. October 25, 2026 includes v0.3 (27 landmarks, audio tour, timeline, collection screen) and v0.4 (book threads, daily hunt, offline service worker, accessibility notes in the commit subject). Later commits: October 30, the One Piece of Land walk. October 31, spoken bridge lines. November 8, an optional prologue and Hanna side quest. November 10, the location catalog and a catalog test. A draft that said 14 commits does not match this bundle.

## Where it lives now

Archived November 13, 2026, 6:21 PM PT. The archive index says the repo was deleted at 6:35 PM PT and the hosting site at 6:38 PM PT. The Cardinal book site was a different project and was not part of this delete.

## What was learned

The archive does not record a separate lesson. The recorded decision is that the campus hunt does not stay up as its own site. Where a later version would live, Dawn or the Cardinal rebuild, is still the index's open pair of options.
