# Assets

No photographs of people are used.

## Decided

- Pixel is the default `data-style`. Notebook, Desk, and Magazine stay switchable.
- Press Start 2P and VT323 are self-hosted Latin woff2 subsets so the page does not call Google at runtime. Licenses are the upstream OFL files.
- The sunset and bird loops are original pixel frames made for this site, not taken from a photo.
- Paper grain is an original fiber field generated for this site. A Wikimedia file named Texture 16 was rejected because it is a photo of book spines, not blank paper.
- Halftone dots, torn-card clip, and the gold tape strip are CSS, not image files.
- Stage icons (stairs, cardinal bird, temple) are original inline SVG pixels.
- Animated thumbs are lazy, with a still poster when `prefers-reduced-motion` is set.
- Nightlight and Lineage are not on the board. Those repo names were not found, and the same paths on artometrics.com return the magazine homepage.
